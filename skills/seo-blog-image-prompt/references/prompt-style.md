# prompt style guide

- prompt เป็นอังกฤษ (image model เข้าใจดีกว่า) แต่ alt text เป็นไทยเสมอ
- ระบุ: subject, สไตล์ (flat illustration / photo / 3D), โทนสี (อิง brand voice ถ้ามี), mood, no text in image, no logo, อัตราส่วน
- cover: เล่าใจความบทความเป็นภาพเดียว ดึงดูด click
- og: เหมือน cover แต่ crop ปลอดภัยกลางภาพ (1200×630, กันขอบโดน crop)
- in-article: ภาพประกอบหัวข้อ H2 นั้นจริง ๆ ไม่ใช่ decoration ลอย
- หลีกเลี่ยง: คนหน้าชัด (สิทธิ์/ความสม่ำเสมอ), ตัวหนังสือในรูป, แบรนด์อื่น
- in-article body ใช้รูปแบบ `![alt ไทย](NN.png)` — publisher จะแทนเป็น public URL ให้อัตโนมัติ
